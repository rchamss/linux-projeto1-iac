## Desafio Linux Server 01 🐧
Repositório para armazenar o primeiro desafio do curso de Linux da Dio.me

Neste desafio fui atribuido em criar um script em um servidor linux para atender as seguintes demandas:
  1. Criar diretórios automatiacamente;
  2. Criar grupos para controle de acesso automaticamente;
  3. Criar um número específico de usuários, com informações e atribuições previamente preescritas.
Após a conclusão desse desafio, foi criado um respositório no Githup para que os arquivos possam ser armazenados e compartilhados.
